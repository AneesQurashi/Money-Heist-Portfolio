# Publish and maintain the Money Heist Portfolio

This website is hosted in the public repository **AneesQurashi/Money-Heist-Portfolio**.

## File structure

- `index.html` — all portfolio sections and exact social profile links
- `style.css` — design and responsive styles; main color #E50914 and background #141414
- `script.js` — navigation, theme/audio toggles, scroll animation, email contact
- `assets/` — the two original portrait photos and favicon
- `resume/Anees_Ahmed_Public_Resume.pdf` — privacy-safe public resume
- `.github/workflows/deploy.yml` — GitHub Pages deployment workflow
- `README.md` — owned by the repository owner; this upload deliberately left it untouched

## Publish the live site

In GitHub, go to **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source. Then open **Actions** and run or rerun the workflow if necessary. The expected URL after successful deployment is **https://aneesqurashi.github.io/Money-Heist-Portfolio/**; check the Pages section for the confirmed live URL.

No GitHub login is required to view a public Pages site. The contact form opens the visitor's email app; it does not send messages via a backend.

## Privacy

Do not upload the original **Anees Ahmed.pdf** CV containing government ID and sensitive details; use only the provided public-safe resume. External social links reflect those supplied by Anees Ahmed.
